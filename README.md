## Sobre o projeto

Esse repositório reúne o material de currículo da comunidade **First Commit-m**:
dois modelos de currículo em Word, prontos pra editar, e um guia de como
transformar prática (labs, cursos, projetos acadêmicos) em conteúdo real de
portfólio - currículo, GitHub e LinkedIn juntos.

A ideia por trás é simples: currículo, GitHub e LinkedIn se sustentam
mutuamente. Um currículo bem escrito sem projetos que comprovem o que está
escrito levanta dúvida - por isso o site também ensina como documentar sua
prática de forma que vire material de portfólio de verdade.

## O que tem no site

- **Modelos de currículo** - dois arquivos `.docx`, um para quem está
  buscando estágio/trainee e outro para quem já tem alguma experiência
  prática e busca uma vaga júnior. Baixe, abra no Word (ou Google Docs) e
  edite por cima.
- **Trilha AWS** - duas trilhas de estudo prontas pra começar (Cloud
  Essentials Knowledge Badge e AWS SimuLearn: Cloud Practitioner), com link
  direto pro AWS Skill Builder.
- **Como documentar** - um padrão simples de 5 passos pra transformar cada
  lab ou projeto em conteúdo de currículo, com um exemplo real preenchido do
  início ao fim.

## Estrutura

```
.
├── index.html          → página principal
├── documentar.html     → guia de como documentar sua prática
└── assets/
    ├── styles.css
    ├── img/             → logos e imagens
    └── docs/            → os dois modelos de currículo (.docx)
```

## Como usar

1. Acesse o [site](https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/).
2. Baixe o modelo de currículo que fizer mais sentido pra você.
3. Se ainda não tem projetos pra colocar nele, comece pela trilha AWS e
   documente sua prática seguindo o padrão explicado no site.
